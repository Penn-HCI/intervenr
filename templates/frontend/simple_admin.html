Quick Actions

To reset tracked TLDs, please upload a .CSV file with a tld column that contains the TLDs that should be tracked and an apply_intervention column if heavy and light interventions should be applied to the column with true and false values as well as an apply_collect_links if links should be collected on the domain. To set intervention groups, please upload a .CSV file with the column user_id and intervention_type. All of the corresponding participants with matching user_id will be set to their given intervention_type. To add new onboarding codes, upload a .CSV file with an onboard_code column. These will all be added. Finally, to offboard users, please upload a .CSV file with a column user_id that corresponds to the users that should be offboarded. For fine tuning or quick adjustments, please use the row display systems.
